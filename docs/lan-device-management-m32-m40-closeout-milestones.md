# 局域网设备管理 M32–M40 收口里程碑

> 状态基线：2026-09-26。M32–M38 已完成仓库验收；M39–M40 必须以新四机环境的真实证据为准。

## M32 上网路线目标完整生命周期

- 任务：统一路线创建、编辑、删除、引用统计和替代迁移；稳定 ID 跨重启保留。
- 验收：使用中的目标不能直接删除；选择替代路线后设备、分组、全局默认和 LAN 默认引用一次迁移；重复提交幂等，失败回滚。
- 状态：已完成，提交 `4c4389e`。

## M33 正式上网路线交互

- 任务：正式页面只使用 Gateway Target 领域接口，隐藏 DHCP tag、option 3/6 和 UCI。
- 验收：新建、编辑、删除均先展示影响和引用；删除引用目标必须选择替代路线。
- 状态：已完成，提交 `73d9ca8`。

## M34 高影响设备策略预览

- 任务：网络与上网、联网权限和限速统一使用 Plan/Apply；展示期望、路由器配置和实际观察。
- 验收：版本变化拒绝提交；未预览不能应用；失败语义不误报为终端已生效。
- 状态：已完成，提交 `9b8099a`。

## M35 DHCP 与地址池安全工作流

- 任务：提供 DHCP 开关、地址池、租期和默认路线的 typed Get/Plan/Apply。
- 验收：拦截网络地址、广播地址、路由器、浮动 IP、网关节点和静态预留冲突；关闭前显示受影响租约与恢复路径；外部或不明 DHCP 只读。
- 状态：已完成，提交 `5ae9606`。

## M36 隐私、类型与模块边界

- 任务：Webhook 设备标识伪匿名；统一能力五态；拆分管理探测与策略包模块。
- 验收：Webhook 不含原始 MAC 和本地审计原因，伪匿名跨重启稳定且设备间不同；未知能力状态失败关闭；原 API 不回归。
- 状态：已完成，提交 `c40b6fa`。

## M37 四区详情与单设备使用管理

- 任务：详情收敛为概览、设备资料、网络与上网、使用管理；单设备可设置休息时段和额度。
- 验收：跨午夜、路由器时区、来源链、下一计划节点、版本冲突和额度单字段变化均有测试；流量和诊断不再占一级标签。
- 状态：已完成，提交 `4a69422`。

## M38 唯一基线与五层矩阵

- 任务：同步产品基线、五层覆盖矩阵和 M32–M38 验收证据；删除失效计划占位符。
- 验收：JSON 唯一源可重新生成 Markdown；所有证据路径存在；没有未经实机证明的 `verified`。
- 状态：已完成；证据见 [`docs/evidence/m32-m38/acceptance.md`](evidence/m32-m38/acceptance.md)。

## M39 四机功能与登录态 UI 收口

- 环境：A `192.168.30.1`、B `192.168.30.244`、C `192.168.30.93`、D `192.168.30.7`、VIP `192.168.30.3`。
- 任务：部署 M38 候选；在登录态正式页面验收四区详情、DHCP、路线生命周期、单设备计划/额度、分组来源、能力缺失与可用组合；安装并验证匹配固件的 eqos。
- 验收：桌面和移动端无阻断问题；所有写入均由 UI 预览并可恢复；A/B 权限边界不被绕过；限速、暂停、计划、额度和路线互不误伤。
- 状态：已完成；三次实机优化、配置恢复与登录态证据见 [`docs/evidence/m39/acceptance.md`](evidence/m39/acceptance.md)。
