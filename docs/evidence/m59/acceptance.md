- 固定优先级为系统默认 → 全局默认 → 低优先级组 → 高优先级组 → 单设备例外，响应包含完整来源链。
- 全局规则覆盖当前设备清单；移除全局规则或成员后会恢复系统默认，分组删除不删除单设备例外。
