# M61 IPv6 等价性验收

日期：2026-09-28

- 原生限速以 MAC 为稳定策略身份，同一条策略同时覆盖设备 IPv4 与 IPv6 流量；后端明确返回 `ipv6State=covered`。
- 修复 eBPF 上下行共享补充时间戳导致的互相干扰，并为低速 TCP policing 设置有界最小突发容量。
- B/C 隔离夹具真实 IPv6 双向 iperf3：2 Mbit/s 上限下下载 1.98 Mbit/s、上传 1.40 Mbit/s；未限速基线约 924–928 Mbit/s。
- 删除策略后双向恢复约 925 Mbit/s；策略 revision 回滚、临时地址、路由及测试进程均自动清理。
- 验收区间沿用“最高速度”而非精确整形语义：持续采样为设定上限的 50%–130%，且基线和回滚吞吐至少为受限值四倍。
- A（`192.168.30.1`）仅计算网络、DHCP、防火墙配置指纹，测试前后完全一致；限速写入仅发生在 B。
- `make test-lan-ipv6` 覆盖产品契约与正式前端；`M61_DEVICE_SMOKE=1 make test-lan-ipv6` 增加真实数据面验收。

结论：`LAN-007` 的产品需求、原型、后端、正式前端和实机证据闭环，IPv4/IPv6 共用一条原生 MAC 策略且可完整回滚。
