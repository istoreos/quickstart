# M30 正式 UI 与旧入口退场验收

状态：通过（仓库、浏览器和生产构建）；OpenWrt 实机交互由 M31 验收。

## 任务结果

- 一级信息架构收敛为“设备 / 分组与计划 / 局域网设置”，规则台账只存在于局域网设置内；正式页面没有经典列表切换。
- 设备列表仅保留身份、存在状态、主要地址、连接、实时流量和最多两个策略摘要。资料、网络与上网、使用限制、用量、诊断进入同一详情抽屉。
- 资料编辑器支持 Unicode 备注、人工品牌/类型、品牌加类型自动视觉、30 个手动图标和恢复自动推荐；原始厂商、可信度、MAC 与历史地址默认折叠。
- 网络与上网编辑器按 Router Context 锁定路线字段，分别显示期望、路由器配置和设备当前状态；联网权限不依赖限速能力。
- floatip、限速能力仅局部降级；安装前先计划并确认，使用 `sessionStorage` 保留原设备、区域和草稿。
- 分组与计划支持默认规则、成员、暂停联网、限速、路线、跨午夜时段、额度、影响预览、单设备例外和来源链。
- 现有有效配置只在确有待接管项时显示一次性迁移卡片；冲突或未知项禁止应用，正常项确认后使用版本校验、快照和回滚后端接管。
- 本地开发缺少 LuCI 语言注入时安全回退，并能加载英文语言包；深色模式补齐页面背景和状态对比度。
