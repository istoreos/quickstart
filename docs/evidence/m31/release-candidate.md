# Quickstart LAN 设备管理 r11 候选说明

本候选用于 M31 内部实机验证，**不是公开发布批准**。

已验证：唯一三栏信息架构、设备清单、中文备注与 DHCP Hostname 分离、品牌/类型/手选图标、上网路线产品语言、能力局部降级、分组来源链、迁移幂等、诊断边界和低堆内存压力。

已知边界：IPv6 静态保留尚不支持；终端路线效果依赖 DHCP 续租证据；Bandix、eqos 和 floatip 都按可选能力处理；多 LAN/VLAN 仍需逐 LAN 实机覆盖；测试软件源无法安装匹配内核的 eqos；没有第二个 floatip 节点；24 小时稳定性仍在采样；公开发布前仍需完成素材产品/法务审查。

回滚基线：`/root/quickstart-backups/m31-predeploy-20260925.tar.gz`。由于自动部署备份文件名存在已记录缺陷，本候选只能使用这份显式、已校验备份恢复，不能依赖 `quickstart.${stamp}.bak`。
