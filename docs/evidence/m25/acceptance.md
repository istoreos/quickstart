## 任务树

- 统一 `Capability` 的状态、原因、动作与期望保留标记。
- 将联网权限的 firewall Adapter 与限速的 eqos Adapter 解耦。

- 提供安装预检、二次确认、执行结果与草稿 token 回传接口。

- 覆盖缺失、停用、错误、不支持、安装取消/失败/成功及竞态变化。

## 验收结论

- **通过**：eqos 不存在或异常不会阻塞 firewall 联网权限读写。
- **通过**：floatip 不存在只影响浮动路线能力，其他策略不被绑定。
- **通过**：取消、空间不足、安装失败均不改变策略，且原样回传草稿 token。
- **通过**：安装成功只返回当前能力和后续 `enable` 动作，不自动应用设备策略。
- **通过**：能力状态在确认后变化会返回冲突，不盲目执行。
- **通过**：前端仅消费统一能力契约，`unsupported` 与缺失契约均安全关闭对应控件。
