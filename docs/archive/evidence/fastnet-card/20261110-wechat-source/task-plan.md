# 微信内置测速源实施与验收

基线：FastNet 当前未提交工作树；设备二进制 SHA256 22af3830122363e51103979a9011fa4d72bdd3822cfc09553ac7c128b94c2ecb，0.8.6 测试候选。原有调度及 Quick 修复单独保存在 baseline/，微信实现不修改它们。

任务树：
1. 官网链接解析：3 秒、256 KiB、下载按钮与官方 HTTPS 链接校验；失败使用指定固定地址。
2. 微信目标：ID wechat/provider tencent/最多2连接/AllowRepeat=true；本轮一次解析，下载明确失败后进入本轮固定地址回退；取消立即退出。
3. 现有候选流先提供微信、再读远端；尊重来源筛选、去重，远端故障不阻断微信；原20秒/总8连接不改。
4. 自动化：解析/回退/EOF/取消/远端故障/去重，Go全包、核心race、vet及diff检查。
5. 设备：微信单源测试；同基线旧二进制和新二进制交错各5轮多源测试；部署候选核心后Quick原入口检查，保护配置、历史LAN、布局、UI和opkg。

验收：功能全部通过，微信有实际字节、能持续正常EOF重开，原预算/取消/资源释放保持；对照记录均值、中位数、CV和备用流量，不将来源接入等同整体CV<=5%达标。真实对照包括所有样本。必要时最多3轮优化，不自动提交、推送或正式发布。

循环：首轮功能验收通过，优化0次；整体带宽波动仍未达到既有CV≤5%目标，单列报告。
