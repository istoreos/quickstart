# FastNet 0.8.8

- Quickstart 外网测速卡片按 WAN、LAN、NAT / IPv6 排列。LAN 下载、上传更清晰，保留独立最近测速时间；浅色、深色、跟随系统以及紧凑触屏显示保持支持。
- 多来源下载优先分散供应商，按各连接实际贡献判断是否保留；启动等待和降速替代均有时间、并发与恢复次数上限，保留原真实字节/时间计量。
- 默认 FastNet 页面与 Quickstart iframe 使用相同快速体验；各入口共享最近结果，按实际测速项目保留历史，最多 32 条，历史不可用时不阻断测速。
- 保留结果优先的快速体验流程、现有 LAN 测速实现与浅深色主题。

本地受控下载回归、Go 全包/race/vet及设备验收已完成。0.8.7 测试候选在 192.168.30.7 的十轮下载均值 893.1 Mbps、CV 2.28%；仅代表该出口与时段。0.8.8 以此下载实现为基础，仅增加卡片显示调整与版本标记。

运行产物为 Linux x86_64、aarch64、ARMv7。ARM 为交叉构建，实际设备验收为 x86_64。外部卡片资源由 luci-app-fastnet 提供，独立运行二进制不包含宿主卡片资源。

本地来源目录 revision 5 与线上 revision 4 分开管理；本次运行程序发布不自动更新 CDN 服务端目录。
