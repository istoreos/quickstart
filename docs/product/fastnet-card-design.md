# 首页「外网测速」卡片

运行 `./scripts/ui-design.sh start`，直接打开首页 <http://127.0.0.1:5180/>。
FastNet 作为独立模块融入既有 Quickstart 首页，采用相同卡片外观、槽位、编辑和响应式规则。
默认与网络接口并排，紧接网络流量和网络连接区域；可在「自定义首页」中移动、隐藏、重新添加、调整行布局和显示形态。

## 卡片主体

```text
┌──────────────────────────────────────┐
│  外网测速                   [测速] ⋮ │
│                                      │
│  ↓ 上次下载          ↑ 上次上传      │
│  942 Mbps            108 Mbps        │
│                                      │
│  上次测速                 今天 14:22 │
│  ──────────────────────────────────  │
│  NAT  全锥形           IPv6  ● 可用  │
│                                      │
│  主宽带 · 默认出口           FastNet │
└──────────────────────────────────────┘
```

主体聚焦外网：上次下载、上传速率，上次测速时间，NAT 类型，IPv6 情况。
速率使用 Mbps，历史结果明确标注“上次”，与实时网络流量卡片区分。
卡片不包含 LAN 测速、首页推荐横幅、历史曲线或新的导航页。
右上角使用与现有卡片一致的「测速」按钮和更多操作菜单。

## 快捷交互

- 点击「测速」直接在本卡片启动外网测试，保留旧结果，底部显示准备、下载、上传、NAT / IPv6 检测等阶段。
  按钮变为「测速中」并禁用重复提交，提供「停止」。完成后更新下载、上传、时间、NAT 和 IPv6。
  正式执行会占用外网带宽；说明放在结果详情中，每次快捷操作直接开始。
- 停止或失败保留上次完整结果，失败原因和「重试」在原卡片显示。
- 没有结果显示「—」「尚未测速」「未检测」；旧结果保留时间并提示可重新测速。
- 系统内置 FastNet 时直接显示结果或未测速状态。缺少组件时，同一卡片显示「安装 FastNet」，
  点击安装后原位显示进度；安装完成进入空态，不自动测速。失败原位重试。
- 组件已安装但服务未启用时，卡片显示「启用服务」。启用不自动测速。
- 更多菜单的「查看上次结果」复用首页已有对话框，包含速率、时间、NAT、IPv6、测试路径及带宽影响说明。
- 隐藏与重新添加由统一首页布局管理，保留组件和检测结果。标准与摘要形态都保留速率、时间、NAT 和 IPv6。

## 能力边界

本提案以路由器默认外网出口为测试范围；NAT 与 IPv6 都指该出口下的路由器检测结果。
不将 NAT 类型当成总体网络健康分，也不承诺应用一定能直连；路由器 IPv6 可用不代表每台 LAN 设备均可用。
后续若增加多出口支持，需先核实 FastNet 实际接口绑定能力，并按出口存储和展示结果。

原型注册、状态与组件都在 `web/src/design/` 中，正式首页目录、后端和两个 FastNet 仓库保持原有内容。
预览注册到现有布局目录并使用统一布局引擎；正式接入时，应将模块注册移入产品目录并连接实际只读状态、安装与测速任务。
预览数据与进度全部模拟，不执行真实安装或网络测速。布局与结果仅保存在本次预览内存中。

## 评审入口

首页右上「设计预览 → FastNet」切换已有结果、未测速、未安装、旧结果、IPv6 异常、服务未启用和失败场景。
也可用首页参数 `?fastnet=empty`、`?fastnet=missing` 等直接打开对应场景。
原 `/design/fastnet` 链接仅重定向回同一首页。

```sh
./scripts/ui-design.sh start
NODE_PATH=/tmp/quickstart-playwright/node_modules \
  node docs/product/ui-design/fastnet-card-review.cjs
```

脚本检查：首页槽位与卡片尺寸、外网信息、直接测速、取消与重试、安装空态、统一模块库、摘要设置、
隐藏与换位后的单实例、手机深浅色，以及无真实网络请求。可设置 `OUTPUT_DIR` 保存截图与报告。
