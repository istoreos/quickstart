# FastNet 配音修订 v3

用户反馈：v2画面可用，但配音机械、节奏慢；恢复原验证过的gange-natural A风格，
不需要字幕。优先保障说话连贯和自然语速，让画面跟随语音，不用静音撑片长。

已确认：服务端音色WAV SHA256仍与v2缓存一致，逐字稿正确；模型与数值参数
沿用A风格，但旧instructions被缩短，开头及加卡操作被切成1–2秒的小段，
时间轴还附加固定片前/片后停顿。前次技术验收不能证明“听起来像真人”。

本轮保留v1/v2及其验收记录，使用独立voice-v3输出。不重录浏览器、不重跑测速、
不重装设备。复用真实原始录像和取景，所有章节重新从无字幕源画面渲染，禁止
把带字幕的旧章节直接拼回。保留产品原有文字和必要章节/操作提示标签。

任务：

1. 核对现有音色参考、逐字稿、API及实际请求；记录已确认与尚未确认的原因。
2. 独立保存用户提供的完整A风格预设，逐字段校验，只替换input。
3. 制作“旧版实际开头/完整A风格连续句群”的短段试听，提供主观比较入口。
4. 按4–15秒左右自然句群生成全部旁白，不再按每个1秒动作生成独立语音。
5. 测量实际时长和停顿；保持音高/速度，减少额外空档，让页面动作跟随旁白。
6. 从原始素材去除字幕重渲染整片与开头预览；不生成SRT或内嵌字幕轨。
7. 验证预设、音色指纹、无变速、无字幕滤镜/轨道、全片解码、响度、原版保留。
8. 最多三次成片技术验收，交付MP4、原始配音、试听、请求回执和报告。

验收不把语速数字等同于自然度：自动检查只能验证参数、时长、静音、字幕和
文件完整性，最终“像真人”的感受需要用户试听判断。未知时不宣称已经通过听感验收。

## 听感反馈

首个连续句群样本7.6秒，用户反馈“语气太赶，需要更自然”。该样本未获听感
通过，不用它替换整片，也不将技术参数一致视为质量通过。接着比较相同内容的
自然句号断句版与Higgs原生speed_slow提示版；两者保留完整A风格数值、speed=1.0，
均无后期变速。待用户试听反馈后再确定全片音轨，字幕移除渲染逻辑已准备。
