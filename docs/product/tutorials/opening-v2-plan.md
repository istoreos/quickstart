# FastNet 开头修订 v2

## 目标与边界

让首次观看的用户在约 20–23 秒内理解：这是 iStoreOS 首页，FastNet 可以测速，
921.4 Mbps 来自一次真实外网下载测试，Quickstart BETA 支持把最近成绩放在首页。
叙事闭环为「首页 → FastNet → 真实测速 → 成绩回首页 → 安装教程」。

保留首版 MP4、字幕、素材与三轮验收记录。本次是用户明确授权的新修订任务，
使用独立输出目录和独立三轮记录；不得删除记录或开启第四轮。安装、结果解读、
BETA 指引和添加卡片章节复用已验证素材，不重新安装、不重跑外网测速。
只补录真实首页进入 FastNet、关闭弹窗回首页的动作；测试过程和 921.4 结果
使用原来同一场实测。不得插值伪造测速数字或拿另一场结果接成同一场。

## 任务树

- R01 定义目标、分镜、验收和三轮上限。
- R02 隔离修订输出，保存首版哈希；核对原始实测与设备状态。
- R03 编写确定性开头录制，彩排定位；补录首页→弹窗→首页，恢复原布局。
- R04 按原音色参数分段生成新旁白，测量真实时长，复用后续旁白。
- R05 编译真实取景、运镜、点击 cue、字幕与匹配转场；复用原后续章节。
- R06 在 Windows 视频服务器渲染整片与开头预览。
- R07 最多三轮检查/修正，记录每轮结果；失败停止并交付诊断，不启动第四轮。
- R08 收集新版 MP4、字幕、manifest、分镜与验收报告，报告原版保留情况。

## 验收

1. 原版 MP4 哈希仍为 04c79d4816dc2da7ffb3a14c8044f81a9b5370d75bb70e4f9009b427c33f19c1。
2. 开头大约 20–23s；若自然语速导致偏差，最多放宽至 25s 并记录。
3. 首页全景先于卡片特写；FastNet 名称先于独立结果特写；BETA 条件在回首页时说明。
4. 首页/卡片→真实打开 FastNet→原场开始/运行→原场 921.4→回首页，来源可追溯。
5. 结果有至少 2s 可读停留；镜头推进平滑，标签不遮住关键按钮/结果。
6. 真实点击在旁白或高亮之后；点击 cue 与计划的误差≤300ms，保留原始时戳。
7. 所有浏览器断言通过；补录前后布局内容相同、无网络配置修改、未新增测速。
8. 1920×1080、固定30fps、H.264/AAC；全片可解码、字幕等于旁白、音量达标。
9. 逐镜头检查全景、聚焦、点击、结果、回首页与衔接；人工视觉结论独立于自动检查。
10. 后续安装/测速/BETA/添加卡片内容保留，整片90–120s；提供独立开头预览。

第一轮实拍检查发现卡片采用整数精度：921.366451 Mbps 在完整界面显示 921.4，
首页按现有规则显示 921。已更正断言，不修改产品界面或实测值。
