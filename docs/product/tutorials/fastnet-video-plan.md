# FastNet 首页卡片首期视频

目标：在授权 Windows 视频服务器完成 90–120 秒中文 MP4，展示真实 FastNet
安装或更新、一次真实测速、Quickstart BETA 更新指引和首页卡片添加。
使用 gange-natural，真实页面录制；软件界面不生成、不虚构数据。

## 任务树

- V01 环境、版本与设备状态预检；记录实际资源哈希。
- V02 定稿分镜与旁白；并发下载表述限定为减少单节点影响。
- V03 建立轻量独立脚本、配置模板和分段 TTS 缓存。
- V04 记录真实安装/更新；同版本重装必须明确标注，不冒充新版本升级。
- V05 录制真实测速；保留结果与测量条件，等待剪辑必须标识。
- V06 展示 BETA 官方下载页及备份要求，添加并保存首页卡片。
- V07 对齐音画、生成字幕、鼠标提示、像素包装和最终 MP4。
- V08 最多三轮成片验收、修正与复验；记录每轮结果。
- V09 核对设备恢复、会话销毁、私有产物排除，交付脚本与成片。

## 边界

只修改首页布局与本次 FastNet 安装/运行所需状态。不变更 DHCP、网络策略、
网关、分组，不触碰主网关。录制前快照并核对安装候选；不把旧包覆盖新运行程序。
当前 BETA 已安装时只展示真实检查与更新方法，不伪造安装过程。
真实测速是本轮明确授权；不作多轮跑分或承诺所有线路都更准确。

所有浏览器录制、TTS、音视频渲染在 Windows 视频服务器运行。
本地负责源码、SSH 编排和必要测试。每个任务的运行证据保存在私有产物目录。

## 验收

- 时长90–120秒，1920×1080、固定帧率、中文旁白和字幕。
- 安装/更新、实际测速、BETA指引、首页放置与刷新持久化均有证据。
- 演示数据不冒充实测；剪短等待显式说明。
- 点击前提示位置；关键结果停留至少3秒；关键提示音画误差目标≤300ms。
- 不泄露会话、密钥、私人设备名、地址、账号和原始录音。
- 记录实际版本、源码、资源、旁白与成片哈希。
- 保存各步骤素材，可单独重做；最终验收最多三轮，失败不标完成。
- 不提交音频、视频、Trace、私有配置和生成缓存。
