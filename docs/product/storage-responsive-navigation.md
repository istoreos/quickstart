# 存储工作台：融入真实 iStoreOS 外壳

日期：2026-11-22。依据用户提供的 `root@192.168.30.7` 手机首页和系统菜单截图修订。
本稿取代此前的局部左栏/手机选择器方案；已有真实系统菜单是唯一的全局导航。

## 最终信息结构

```text
iStoreOS 现有顶栏：菜单按钮 / 品牌 / 原有操作
  └─ 现有系统侧栏
      └─ 网络存储
          └─ 硬盘与存储（正式接入建议，具体菜单注册待接入）
              ├─ 硬盘与分区
              ├─ 存储池与卷
              ├─ RAID 阵列
              └─ 任务记录
```

上面四项是同一页面内的工作区标签，不新增四套系统菜单或第二个侧栏。
首页的存储摘要卡片保留快捷入口；首页本身保持原有真实布局。

| 层级 | 负责什么 | 交互 |
| --- | --- | --- |
| 系统外壳 | 在网络、Docker、系统和存储等功能间切换 | 复用现有汉堡按钮及系统侧栏；不重建菜单项/搜索/品牌栏 |
| 存储页面 | 当前模块内四个工作区 | 桌面横向完整名称；手机缩为“硬盘 / 存储池 / RAID / 任务” |
| 资源详情 | 查看一块盘、一个卷或一项任务 | 右侧详情；手机全宽，关闭返回原工作区和位置 |

## 页面应删掉哪些东西

1. 删除 design 外壳额外添加的“首页 / 硬盘与存储”顶部导航条，首页和存储页均不再显示。
2. 删除存储子页面的局部左侧导航，避免与真实系统侧栏争夺空间。
3. 删除标题旁重复的“任务记录 0”；任务角标仅表示进行中数量，零时省略。
4. 手机不再使用另一个汉堡菜单，也不需要下拉选择器：四项固定、简短且可同时显示，直接点选即可。

页面自己的标题和返回首页的内容区面包屑保留；它们位于宿主顶栏下方，
不是插到宿主顶栏上方的第二条全局导航。

## 细节规则

- 工作区与 `?tab=` 同步，直接链接与浏览器前进/后退保持当前项。
- 桌面使用“硬盘与分区 / 存储池与卷 / RAID 阵列 / 任务记录”；窄内容区显示短名，读屏名称仍使用完整名称。
- 仅替换显示名称，四项顺序、身份和能力不变；不用为手机单独维护业务逻辑。
- 提醒按钮位于标签行末端，手机只显示铃铛和未解决问题数量；已读不代表问题已解决。
- 池/硬盘的对象选择仍在工作区内部横向展示，不新增第三层侧栏。
- 普通 EXT4、RAID 处理函数、接口与准入逻辑不因布局变化而改变。
- 系统菜单展开后遮罩内容；选择目的地后由宿主收起。资源详情打开时背景暂停交互。
- 有编辑内容或正在执行任务时，按相应页面已有的离开规则处理；执行任务独立于菜单切换。
- 不叠加两个活动模态层。详情内部提供关闭/返回；若宿主允许在详情期间唤起系统菜单，先处理详情离开，再切换。

## 原型与真实接入边界

当前在 design 中增加 `IStoreHostShellPrototype.vue`，按用户截图呈现品牌顶栏、菜单搜索、
手机遮罩、网络存储分组和存储入口，替换原来的灰色系统占位。
这是可操作的宿主评审外壳，正式 LuCI 外壳菜单继续由主题/宿主拥有；不把这份模拟菜单注册到设备。
网络存储中具体注册哪个菜单项、旧磁盘/挂载/RAID 地址如何重定向，以及宿主弹层互斥，
在正式接入时完成。本次没有部署或修改 `192.168.30.7`。
现有设计入口仍可从首页“硬盘与存储”卡片进入，存储页面包屑可返回首页。

## 完整效果版

访问 `/?presentation=1` 看首页，访问 `/storage?presentation=1` 直接看存储页。
该参数在首页、系统菜单和工作区导航间保留；它隐藏评审场景条和方案切换器，方便判断真实页面层次。
不带参数的地址仍保留原型检查工具。所有磁盘、任务和 RAID 响应仍为示例数据。

- 手机使用截图中的双行品牌/操作顶栏，菜单从左侧覆盖；打开时焦点进入菜单容器，不自动唤起搜索键盘。
- 桌面保持一个 200px 系统菜单，页面不新增侧栏；导航到新模块后从顶部展示，同一模块内工作区由 URL 切换。
- 系统菜单中的未接入业务只进入原业务占位，退出登录禁用；不调用真实系统配置或退出接口。
- 首页的布局设置由顶部图标转交给原首页处理函数，避免重写业务。
- 详情/操作弹层打开时，宿主评审菜单与顶栏暂停交互；关闭后恢复，防止叠加活动模态层。
- 原型的模态检测使用 DOM 观察，仅用于评审联动。正式版本应接宿主已有的路由/弹层协议，不复制这套检测作为生产架构。
