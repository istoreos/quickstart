# M53～M64 产品闭环与发布计划

> 日期：2026-09-28  
> 原则：不增加一级技术页面；主路由 A 只读；所有有状态验证必须在隔离环境或 B/C/D 执行；未观察到的数据面效果不得标记为完成。

| 里程碑 | 任务树 | 可测试验收标准 |
| --- | --- | --- |
| M53 覆盖矩阵校准 | 盘点 partial → 区分实现/证据债 → 分配唯一关闭里程碑 → 增加一致性门禁 | 55 项均有当前事实；所有 partial 唯一映射到 M54～M64；无过期 M39/M40 blocker |
| M54 隔离测试实验室 | 安全拓扑 → fixture → 故障注入 seam → 自动恢复 | A 零写入；DHCP/firewall/floatip/NetPolicy 故障可重复注入；异常退出自动清理 |
| M55 设备身份与地址 | 中文备注/ASCII hostname → 手动设备合并 → 当前/历史地址 → DHCP 地址池 | 无效 hostname 零写入且 dnsmasq 健康；设备无重复；地址池冲突、关闭、恢复可验证 |
| M56 角色与能力降级 | DHCP authority 五态 → 缺失 Adapter → 安装/恢复 → 草稿保持 | 无权限时只读；缺失只锁对应任务；安装后返回原任务但不自动应用 |
| M57 上网路线闭环 | 默认/分组/设备优先级 → DNS 跟随 → 不可达恢复 → 浮动路线 | 最终来源唯一可解释；失败有下一步；无半配置和无关服务重载 |
| M58 事务与迁移 | 首次迁移/冲突/重试 → 步骤失败 → 回滚失败 → 恢复状态 | 正确区分 rolled_back/recovery_required；重复提交幂等；冲突零写入 |
| M59 分组、批量与时段 | 全局默认 → 组 → 设备例外 → 批量计划 → 跨午夜 | 优先级正确；每服务每批最多重载一次；时段进入、退出、跨午夜实测通过 |
| M60 配额与历史 | 计数 → notify/block → 周期恢复 → 24 小时资源预算 | 配额动作和恢复正确；历史按需加载；内存、文件、写入频率有界 |
| M61 IPv6 等价性 | IPv6 fixture → MAC 统一身份 → 双向限速 → 回滚 | IPv6 真实吞吐受限；IPv4/IPv6 共用策略；回滚恢复且无 IPv4 回归 |
| M62 正式 UI 收口 | 组合筛选 → 上下文保持 → 地址历史 → 审计 → 响应式/无障碍 | 桌面/平板/手机、中英文、明暗主题通过；普通界面不泄漏内部实现名词 |
| M63 高级工具 | 导出/dry-run 导入 → 安全探测 → Webhook 退避 | 冲突导入零写入；探测严格限制目标；Webhook 伪匿名且失败不阻塞核心任务 |
| M64 发布候选 | 干净构建 → 包集 → B 灰度 → 24h soak → 升降级/回滚 → Go/No-Go | 发布物可复现；B 24h 稳定；矩阵 P0 全绿；A 不自动部署；生成最终报告 |

## 固定产品结构

```text
设备列表
  → 设备详情：资料、地址与上网、使用管理
  → 局域网设置：网络服务、上网路线、规则台账
      → 高级：执行方式、迁移、诊断、导入导出
```

每个用户写入任务只跨一个深 Module Interface。DHCP、firewall、floatip、NetPolicy 与历史 Bandix 都是内部 Adapter；页面不得拼装 UCI、命令或 Provider 请求。
