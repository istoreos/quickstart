# 交互原型目录

本目录保存用于产品评审和交互验证的可运行原型。原型是设计证据，不是生产代码，不应被前端构建或固件打包引用。

## 目录约定

每个主题使用独立目录：

```text
docs/prototypes/<topic>/
├─ README.md       目标、状态、运行方式和结论
├─ index.html      可直接运行的原型入口
└─ assets/         仅在确有独立资源时创建
```

要求：

- 目录名使用稳定的英文主题名，不加入日期或版本号；
- 方案差异通过 URL 参数或原型内切换器呈现；
- `README.md` 记录原型问题、推荐方案、验证状态和上游文档；
- 确认后的产品结论写回正式产品文档，原型保留为观察依据；
- 原型不得调用真实写接口，不得成为生产页面的运行依赖；
- 废弃原型保留目录并标记 `archived`，避免读者误认为仍是当前方案。
